# ai-portfolio

Три невеликі проєкти про побудову AI-застосунків: від простого API до RAG-пошуку по документах.

| Проєкт | Що всередині |
|---|---|
| [01-fastapi-api](01-fastapi-api) | FastAPI-сервіс з REST-ендпоінтами, валідацією і тестами |
| [02-llm-chat](02-llm-chat) | Чат із LLM, потокова відповідь (streaming) і обробка помилок |
| [03-rag](03-rag) | Пошук по документах з відповідями та цитатами з джерелами |
